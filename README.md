## 📂 Progetti Principali

### 🧠 CRM — Gestione Clienti (Full-Stack)

Applicazione CRM full-stack ispirata a flussi di lavoro reali in contact center.

**Funzionalità principali:**
- Autenticazione JWT con controllo degli accessi basato su ruoli (Admin/Operatore)
- Database PostgreSQL con paginazione, ricerca e ordinamento lato server
- API REST con Express e middleware per la gestione dei permessi
- Pannello admin per la gestione degli utenti
- Interfaccia responsive: tabella (desktop) + card view (mobile)
- Ricerca in tempo reale con ottimizzazione debounce
- Deploy su Vercel + Render

🔗 Live: [https://crm-project-theta-six.vercel.app/](https://crm-project-theta-six.vercel.app/)
🔗 Codice: [https://github.com/DavideB96/crm-project](https://github.com/DavideB96/crm-project)
